Design Criteria

  • Size — Prototype should fit within the size dimensions of a single ISS Locker.
  • Goal — Solution should imitate washing a medium men's polo in the sink and wringing it out.
  • Function — Project must work in zero-gravity on a spacecraft.
  • Limitations — Projects must not create lots of vibrations or spin significantly to not disrupt spacecraft.
